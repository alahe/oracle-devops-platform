# 📑 Analytics Publisher Ataskaitų Katalogas (`publisher-reports/`)

Šiame kataloge yra Oracle Analytics Publisher ataskaitų šablonai (`.rtf`, `.xpt`) ir duomenų modeliai (`.xdm`).

---

## 🚀 Operacijos

- **Katalogo struktūra:** `Custom/` (visos pasirinktinės kūrėjo ataskaitos).
- **Automatizuotas diegimas:**
  ```bash
  ./scripts/publisher/deploy-publisher-reports.sh
  ```
- **Katalogo atsarginė kopija ir eksportavimas:**
  ```bash
  ./scripts/publisher/backup-publisher-catalog.sh
  ```
