# Nordic Financial Theme for Oracle APEX (Universal Theme 42)

This directory contains the corporate financial styling assets for Oracle APEX modernization projects.

## Included Files
- `nordic-financial-theme.css`: Custom CSS with variables, typography, high-contrast financial table formatting, and button styling.
- `theme_roller_nordic_financial.json`: Theme Roller configuration preset for 1-click import into Oracle APEX Universal Theme (Theme 42).

## Installation in Oracle APEX
1. Open your APEX Application in **App Builder**.
2. Run the application and open the developer toolbar at the bottom.
3. Click **Theme Roller**.
4. Click **Import** and select `theme_roller_nordic_financial.json`.
5. Under **Custom CSS**, paste the contents of `nordic-financial-theme.css` (or link it via **Shared Components > Static Application Files**).
6. Click **Save As** > Set as Current Style.
