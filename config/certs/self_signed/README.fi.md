# ⚠️ Tilapäinen Itse allekirjoitettu sertifikaatti (vaihtoehto 4)

Tämä hakemisto sisältää dynaamisesti luodun itse allekirjoitetun sertifikaatin (`self_signed.crt` ja `self_signed.key`).

## Ominaisuudet ja tila:
* **Taso:** **Vaihtoehto 4 (Alin luottamaton varatila)**
* **Tila:** ⚠️ **Ei-luotettu (Untrusted)**
* **Selainkokemus:** Selain näyttää varoituksen *"Ei suojattu / Yhteytesi ei ole yksityinen"*.
* **Käyttö:** Automaattinen varajärjestelmä vain silloin, kun julkista verkkotunnusta, yrityksen PKI:tä tai paikallista CA:ta ei voida käyttää (`TLS_ALLOWED_LEVEL=permissive`).
