# 🌐 Avalik Arendusdomeen & Avalik CA (Variant 1)

See kataloog sisaldab avaliku FQDN domeeni (nt `*.local.firma.ee` ➡️ `127.0.0.1`) ja avaliku CA poolt allkirjastatud sertifikaati:
* `public_cert.crt` — Avaliku domeeni sertifikaat
* `public_key.key` — Privaatvõti

## Omadused ja Olek:
* **Tase:** **Variant 1 (Toodangulaadne parim praktika)**
* **Staatus:** 🟢 **Globaalselt usaldatud (Global CA)**
* **Tulemus Brauseris:** 100% roheline tabalukk igas seadmes ilma ühegi lokaalse seadistuseta.
