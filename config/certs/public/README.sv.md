# 🌐 Publik domän & global CA (alternativ 1)

Denna katalog innehåller certifikat signerade av en global certifikatutfärdare (t.ex. Let's Encrypt) för publika FQDN (`*.local.foretag.se` ➡️ `127.0.0.1`):
* `public_cert.crt` — Publikt domäncertifikat
* `public_key.key` — Privat nyckel

* **Nivå:** **Alternativ 1 (Bästa praxis för produktion)**
* **Status:** 🟢 **Globalt betrodd (Global CA)**
* **Webbläsarresultat:** 100% grönt hänglås på alla enheter utan lokal certifikatinstallation.
