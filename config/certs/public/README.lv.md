# 🌐 Publisks Domēns un Globālā CA (variants 1)

Šajā direktorijā tiek glabāti publiska FQDN domēna (`*.local.uznemums.lv` ➡️ `127.0.0.1`) un globāli uzticamas CA (piemēram, Let's Encrypt) parakstīti sertifikāti:
* `public_cert.crt` — Publiskā domēna sertifikāts
* `public_key.key` — Privātā atslēga

## Statuss un Pārlūka Darbība:
* **Līmenis:** **Variants 1 (Ražošanas līmeņa labākā prakse)**
* **Statuss:** 🟢 **Globāli uzticams (Global CA)**
* **Rezultāts Pārlūkā:** 100% zaļa slēdzene visās ierīcēs bez manuālas vietējās sertifikātu instalēšanas.
