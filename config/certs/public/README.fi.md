# 🌐 Julkinen toimialue & globaali CA (vaihtoehto 1)

Tämä hakemisto sisältää julkisen FQDN-verkkotunnuksen (esim. `*.local.yritys.fi` ➡️ `127.0.0.1`) ja globaalin CA:n (kuten Let's Encrypt) allekirjoittaman sertifikaatin:
* `public_cert.crt` — Julkisen toimialueen sertifikaatti
* `public_key.key` — Yksityinen avain

## Ominaisuudet ja tila:
* **Taso:** **Vaihtoehto 1 (Tuotantotasoinen paras käytäntö)**
* **Tila:** 🟢 **Globaalisti luotettu (Global CA)**
* **Selainkokemus:** 100% vihreä lukkokuvake kaikilla laitteilla ilman manuaalisia paikallisia asennuksia.
