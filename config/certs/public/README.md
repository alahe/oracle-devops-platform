# 🌐 Public Domain & Global CA Certificates (Option 1)

This directory stores certificates signed by a globally trusted Certificate Authority (e.g. Let's Encrypt) for public FQDNs (`*.local.example.com` ➡️ `127.0.0.1`):
* `public_cert.crt` — Public domain certificate
* `public_key.key` — Private key
