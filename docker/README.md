# 🐳 Container Build Templates (`docker/`)

This directory contains container build scripts, Dockerfiles, and runtime configurations for custom local container images.

---

## 📁 Subdirectories

- **[apex/](apex/README.md):** `localhost/oracle-free-apex:latest` (Oracle 23ai Free DB with pre-installed APEX 26.1).
- **[forms/](forms/README.md):** `localhost/oracle-forms:14.1.2` (Oracle Forms 14c Services runtime container).
- **[publisher/](publisher/README.md):** `localhost/oracle-publisher:latest` (Oracle Analytics Publisher 2025 container).
- **[forms-publisher/](forms-publisher/README.md):** `localhost/oracle-forms-publisher:14c-2025` (Consolidated Forms 14c + Publisher container).
- **[web-ide/](web-ide/README.md):** `localhost/oracle-web-ide:latest` (Browser-based VS Code with Oracle SQL Developer & extensions).
