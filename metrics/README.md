# 📊 Benchmark & Performance Metrics Directory (`metrics/`)

This directory persists version-controlled benchmark measurements and step execution timings (Rule 1).

---

## 📁 Key Files

- **`setup_benchmarks.json`**: Exact duration of setup steps in seconds (JSON format).
- **`setup_benchmarks.env`**: Environment key-value pairs of step benchmarks.
- **`devhub_browser_blueprints_benchmarks.json`**: E2E browser and API test metrics.

*(Note: Full verbose installation logs remain strictly local under `install_logs/` and are excluded from Git).*
