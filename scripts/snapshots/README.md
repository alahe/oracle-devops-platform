# Hetktõmmiste (Golden Snapshots) Halduse Skriptid

- **`create-golden-snapshots.sh`:** Loob andmemahtude hetktõmmise kausta `golden-snapshots/`.
- **`restore-golden-snapshots.sh`:** Taastab andmemahud viimasest salvestatud hetktõmmisest.
- **`clean-golden-snapshots.sh`:** Kustutab vanad hetktõmmised kettamahu vabastamiseks.
