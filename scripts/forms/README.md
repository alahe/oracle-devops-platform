# Oracle Forms 14c Operatsioonide Skriptid

- **`build-forms-image.sh`:** Ehitab `localhost/oracle-forms:14.1.2` konteineripildi.
- **`compile-form.sh`:** Kompileerib `.fmb` vormi käsurealt `.fmx`-iks.
- **`deploy-forms-apps.sh`:** Tarnib vormid ja menüüd konteinerisse.
- **`status-forms.sh`:** Kontrollib Forms 14c ja WebLogic teenuste tervist.
