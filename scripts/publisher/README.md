# Analytics Publisher Operatsioonide Skriptid

- **`status-publisher.sh`:** Kontrollib Publisheri teenuse ja andmeallikate staatust.
- **`restart-publisher.sh`:** Taaskäivitab Publisheri WebLogic konteineri.
- **`deploy-publisher-reports.sh`:** Sünkroniseerib ja paigaldab aruanded kataloogi.
- **`backup-publisher-catalog.sh`:** Varundab Publisheri aruannete kataloogi.
