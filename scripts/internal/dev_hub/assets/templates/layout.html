📚 Töövoogude Juhendid & Tööriistad Põhjalik ülevaade arhitektuuridest, paroolivabast autentimisest ja taastamisest
🏗️ 1. Uue Keskkonna Loomine & Blueprinti Valik

Paigalda ja käivita täielik Oracle 23ai & APEX arenduskeskkond minutitega:

  • Vali sobiv mudel: 11 kureeritud blueprinti (DB, Forms, Publisher, Web IDE).
  • Täisautomaatne käivitus: üks käsk seadistab andmebaasid, APEXi ja SEPS Walleti.
  • Sujuv ümberlülitus: vaheta blueprintide vahel puhtalt ja andmekaota.
🖱️ 2. 1-Kliki Zero-Trust Portaalide Avamine

Mugav ja turvaline autentimine ilma paroolide lekkimiseta brauseri URL-is:

  • 1. Klõpsa teenuse nupule: nt 🛠️ Ava APEX Tööruum →.
  • 2. Sihtkoht avaneb uuel vahekaardil: kasutajanimi on automaatselt eeltäidetud.
  • 3. Parool kopeeritakse mällu: dekrüpteeritakse turvaliselt SEPS Walletist.
  • 4. Kleebi ja logi sisse: vajuta parooliväljal Ctrl+V või Cmd+V.
  • ⏱️ SQL Developer Web: esmasel avamisel võtab lehe laadimine ja sessiooni käivitus ~10–15 sekundit aega.
🔑 3. SEPS Wallet & Paroolide Haldus

Kõik andmebaasi kontod ja volitused ühes turvalises krüpteeritud maatriksis:

  • Kasutajanimi: klõps kopeerib konto nime (nt USER_DEVELOPER).
  • Parooli nupp: kopeerib dekrüpteeritud parooli otse lõikelauale.
  • TNS Alias: kopeerib ühenduse nime (nt DB_PROXY_DEV).
  • Zero-Trust: paroolid ei salvestu tekstifailidesse ega käsurea logidesse.
💻 4. VS Code & SQLcl Terminali Seadistus

Ühenda kohalikud arendustööriistad paroolivabalt läbi SEPS Walleti:

  • VS Code Integratsioon: automaatne ühenduste registreerimine SQL Developeri laiendusse.
  • Paroolivaba SQLcl: ava SQLcl ilma paroole sisestamata (sql /@DB_PROXY_DEV).
  • Keychain integreeritus: turvaline sünkroonimine operatsioonisüsteemi võtmehoidlaga.
⚙️ 5. Tervisekontroll & Diagnostika

Keskkonna elutsükli, võrguühenduste ja hetktõmmiste kiirkäsud:

  • Veebiteenuste test: kontrolli HTTP/HTTPS otspunkte (APEX, ORDS, Forms, Publisher).
  • Walleti test: verifitseeri andmebaasi SEPS Wallet ühenduvus ja TNS aliased.
  • Kuldne hetktõmmis: taasta keskkond vigadeta algseisu ~15 sekundiga.
💡 Algaja Meelespea & Levinumad Mured (FAQ & Veaotsing) Praktilised lahendused mälu, portide, sertifikaatide ja andmebaasi taastamise küsimustes

🧠 Konteineri Muutmälu (RAM) Nõue (Min 4–8 GB)

Oracle 23ai Free vajab töötamiseks vähemalt 2.5 GB RAM-i. Kui Podmani või Dockeri virtuaalmasinal on alla 4 GB mälu, peatub konteiner ootamatult (OOM Killer / exit code 137).

# Kontrolli ja suurenda Podman VM muutmälu:
podman machine stop
podman machine set --memory 8192 --cpus 4
podman machine start

🔌 Pordi Konfliktid (8448, 1521, 8080 Hõivatud)

Kui terminal annab vea bind: address already in use, töötab taustal teine veebiserver või Oracle listener.

# Tuvasta porti hõivav protsess:
lsof -i :8448 # või lsof -i :1521
# Porti saab muuta ka failis .env (nt HOST_HTTPS_PORT=8449)

🔒 Brauseri "Ühendus pole privaatne" Hoiatus (SSL)

HTTPS (https://localhost:8448) kasutab lokaalset isesertifitseeritud sertifikaati. Klõpsa brauseris "Advanced" → "Proceed to localhost" või lisa sertifikaat süsteemi usaldusnimekirja:

# macOS usaldus (lisab Keychaini):
./scripts/certs/trust-local-cert-mac.sh
# Windows usaldus (Run as Administrator):
./scripts/certs/trust-local-cert.cmd

🔐 Kus Asuvad Paroolid? (SEPS Wallet vs .txt failid)

Zero-Trust reeglite järgi ei kirjutata paroole KUNAGI kettale tekstifailidesse. Need asuvad krüpteeritult SEPS Walletis (config/wallet/).

# Kuva parool käsureal või kopeeri lõikelauale (-c):
./scripts/get-password.sh DB_PROXY_DEV
./scripts/get-password.sh DB_PROXY_DEV -c

⚡ Algseisu Taastamine Ilma 12 Minutit Ootamata (~15s)

Kui katsetuste käigus läks andmebaas sassi, ei pea uuesti tegema pikka paigaldust. Kuldne hetktõmmis taastab puhta algseisu umbes 15 sekundiga:

# Taasta valitud kavandi puhas algseis:
./scripts/snapshots/restore-golden-snapshots.sh

🌙 Keskkonna Peatamine ja Uuesti Käivitamine
